Metric Definitions

BLEU
Bilingual Evaluation Understudy - 0 to 100 - higher = more n-gram overlap
chrF
Character F-score - 0 to 100 - better for morphologically rich languages
TER
Translation Edit Rate - 0 to inf - lower = fewer edits needed
ROUGE-L
Longest Common Subsequence F1 - 0 to 1 - higher is better
BERTScore
Semantic similarity via BERT embeddings - 0 to 1 - higher is better
WER
Word Error Rate for ASR - 0 to 1 - lower = fewer word mistakes
CER
Character Error Rate - 0 to 1 - lower is better
RTF
Real-Time Factor = proc_time/audio_duration - below 1 means real-time capable
Throughput
Tokens translated per second - higher is faster inference
p95 Latency
95th percentile response time ms - the worst common case
